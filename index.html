Recap: what we have learned

Here is a quick reminder of each topic.

Types of fractions

Proper: the top is smaller than the bottom, like {3/4}. Improper: the top is the same or bigger, like {7/4}. Mixed: a whole number and a fraction, like {1 3/4}.

Simplifying

Divide the top and bottom by the same number until only 1 goes into both. {12/18} = {2/3}.

Adding and subtracting

Same denominators: only add or subtract the numerators. Different denominators: find a common denominator first. {2/3} + {1/4} = {8/12} + {3/12} = {11/12}.

Multiplying

Multiply the numerators, then multiply the denominators, then simplify. {2/3} × {3/5} = {6/15} = {2/5}. For a fraction of an amount, divide by the denominator and multiply by the numerator.

Dividing

To divide a fraction by a whole number, multiply the denominator. {3/4} ÷ 2 = {3/8}. Extension: to divide by a fraction, keep, flip, multiply.

Mistakes to watch for

Never add the denominators: {3/8} + {2/8} = {5/8}, not {5/16}. When you simplify, divide the top and bottom by the same number. Always check the question asks for simplest form or a mixed number.

Up next

Now that we can work with fractions, let us compare their sizes and find the biggest and smallest.

Comparing fractions

Comparing means working out which fraction is bigger, which is smaller, or whether they are equal. We use these signs: < means less than, > means greater than and = means equal to.

Same denominator

The parts are the same size, so the fraction with more parts is bigger. The bigger the numerator, the bigger the fraction.

{3/8} < {5/8}

[[3/8]][[5/8]]

Same numerator

You have the same number of parts, but the denominator tells you how big each part is. A bigger denominator means the whole is cut into more pieces, so each piece is smaller.

{1/3} > {1/5} and {3/4} > {3/8}

[[1/3]][[1/5]]

Different denominators

Change the fractions so they have the same denominator, then compare the numerators.

Which is bigger, {3/4} or {5/8}?

The common denominator is 8. {3/4} = {6/8}.

{6/8} is bigger than {5/8}, so {3/4} > {5/8}.

Ordering a set of fractions

Write every fraction with the same denominator, put the numerators in order, then write the original fractions in that order.

Order {3/4}, {5/6} and {2/3}, smallest first

The common denominator is 12. {3/4} = {9/12}, {5/6} = {10/12} and {2/3} = {8/12}.

The order of the numerators is 8, 9, 10, so the order is {2/3}, {3/4}, {5/6}.

Mixed numbers and fractions bigger than 1

Compare the whole numbers first. {2 1/4} is bigger than {1 7/8} because 2 is bigger than 1.

If the whole numbers are the same, compare the fraction parts. {3 1/2} and {3 3/5}: {1/2} = {5/10} and {3/5} = {6/10}, so {3 3/5} is bigger.

For improper fractions, change them to a common denominator, or change them to mixed numbers.

Quick check: half and one whole

Compare a fraction to {1/2}. {3/7} is less than {1/2} because half of 7 is 3.5 and 3 is smaller. {5/8} is more than {1/2} because half of 8 is 4 and 5 is bigger.

Fractions, decimals and percentages

These are worth remembering. They are another way to compare sizes.

{1/2} = 0.5 = 50%. {1/4} = 0.25 = 25%. {3/4} = 0.75 = 75%. {1/5} = 0.2 = 20%. {1/10} = 0.1 = 10%.
